# SA Delta Classroom

This is the frontend portion of the SA Delta Classroom monorepo. The `client/` directory contains the React + Vite application. The `server/` and `supabase/` directories will be added in the next stages.

## Frontend deployment on Render
- Root Directory: `client`
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`
- Environment variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_API_URL`

Extract this ZIP before uploading its contents to GitHub.
